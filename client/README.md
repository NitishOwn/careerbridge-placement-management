# CareerBridge Frontend

React + Vite frontend for the CareerBridge Placement & Recruitment Management System.

## Run

```bash
npm install
npm run dev
```

The frontend expects the backend API at `http://localhost:5001`. To change it, copy `.env.example` to `.env` and set `VITE_API_URL`.

## Features

- Student/recruiter registration and login
- JWT-based authenticated requests
- Job listing and search
- Student job applications and application tracking
- Recruiter job posting
- Recruiter applicant management and status updates
